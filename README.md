# DevFolio

A personal portfolio website showcasing my skills and projects.

## Overview

DevFolio is a responsive single-page portfolio website built using HTML, CSS, and Bootstrap. It's designed to present my profile, skills, services, work, blog, and contact information in an engaging and professional manner.

## Technologies Used

* **HTML:** For the basic structure and content of the website.
* **CSS:** For custom styling and layout enhancements.
* **Bootstrap:** A CSS framework used for responsive design and pre-built UI components.
* **Font Awesome:** For icons used throughout the website.

## Features

* **Responsive Design:** Adapts seamlessly to different screen sizes (desktop, tablet, mobile) thanks to Bootstrap's grid system.
* **Navigation Bar:** A fixed top navigation bar with smooth scrolling to different sections.
* **Hero Section:** An introductory section with a dynamic typing animation.
* **About Section:** Presents personal information, skills with progress bars, and a brief bio.
* **Services Section:** Highlights the services offered with engaging icon cards.
* **Counter Section:** Displays key statistics with animated counters.
* **Portfolio Section:** Showcases projects with image cards and a plus icon overlay.
* **Testimonial Section:** Features client testimonials in a fading carousel.
* **Blog Section:** Displays blog posts with categories and author information.
* **Contact Section:** Includes a form to send messages and contact details.
* **Custom Styling:** Extensive use of custom CSS to enhance and override default Bootstrap styles.
